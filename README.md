# HydroSteward

<img width="1920" height="895" alt="hydrosteward" src="https://github.com/user-attachments/assets/e0e44d8e-9b99-4a0a-9477-622502ec8489" />

AI-assisted water monitoring and control, built for the Xylem Global Student Innovation Challenge 2026 (Challenge 1: Water Quantity).

All data is SIMULATED. Assumed values are marked in the code.

- index.html: the dashboard (open the live page)
- hydrosteward_export.py: building scenario, detector, and valve control (writes hydrosteward_data.json)
- hydrosteward_cooling.py: data-center cooling module (writes cooling_data.json)

To run: pip install numpy, then python hydrosteward_export.py
